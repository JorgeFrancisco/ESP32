# ESP32

ESP-IDF relay projects for the ESP32-H2 and ESP32-C6. Each folder is an
independent ESP-IDF project with its own README, build instructions and
configuration.

| Project | Target | Protocol | Description |
| ------- | ------ | -------- | ----------- |
| [H2-Zigbee](H2-Zigbee) | ESP32-H2 | Zigbee 3.0 | On/Off Light (router) driving a relay, with BOOT pairing, an RGB status LED and `power_on_behavior` support. Tested with Zigbee2MQTT. |
| [H2-Thread](H2-Thread) | ESP32-H2 | Matter over Thread | On/Off Plug-in Unit driving a relay, with a BOOT factory reset, an RGB status LED, per-board factory data and a read-only REST API. |
| [C6-Thread](C6-Thread) | ESP32-C6 | Matter over Thread | Port of H2-Thread to the ESP32-C6 with a 16 MB partition table (4 MB OTA slots, LittleFS storage and core dump). |
| [C6-Relay-X1](C6-Relay-X1) | ESP32-C6 | Matter over Thread | Port of C6-Thread to the ESP32-C6-Relay_X1 single relay board (ESP32-C6-WROOM-1, 4 MB flash, relay on GPIO19, single-color status LED). |

All projects are built with ESP-IDF v5.5.5. The Matter projects use
`espressif/esp_matter` 1.6 and the Zigbee project uses
`espressif/esp-zigbee-lib` 2.0.4, both from the ESP Component Registry.

## Getting started

```powershell
git clone https://github.com/JorgeFrancisco/ESP32.git
cd ESP32\H2-Thread
idf.py build
```

See the README of each project for the full build, flash and commissioning
steps.

## Windows path length

The `esp_matter` package contains files with very long names. With Windows long
paths disabled (the default, 260 characters), the Matter project folder must be
at most 42 characters long (for example `C:\Projetos\ESP32\H2-Thread` has
27). See "Windows path length" in the H2-Thread or C6-Thread README.

## Factory data

Per-board factory data (device attestation certificate, its private key and the
pairing codes) is private and must never be committed. The root `.gitignore`
excludes the `*-factory-data/` folders, and each Matter project ignores the
`out/` folder generated by `esp-matter-mfg-tool`.
